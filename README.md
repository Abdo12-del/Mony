# نبض أيراد — AYRD

مشروع مفتوح المصدر لمتابعة السعر المنشور لسهم **AYRADE (AYRD)** في بورصة الجزائر، بواجهة عربية. يتكون من موقع ثابت متجاوب، واجهة API على Vercel تقرأ صفحة SGBV الرسمية، وتطبيق Android أصلي (Kotlin) للفحص الدوري والتنبيهات المحلية. يتيح إدخال كمية أسهم AYRD التي يملكها المستخدم وحساب قيمة تقديرية من آخر سعر منشور؛ الكمية محفوظة محلياً على الجهاز ولا تُرسل إلى الخادم. يبدأ نطاق المحفظة حالياً بسهم AYRADE، ويمكن توسيعه لاحقاً لبقية الشركات بعد إضافة مصادرها الرسمية.

> المشروع غير تابع لبورصة الجزائر (SGBV) أو AYRADE، والبيانات للمتابعة الإعلامية فقط وليست نصيحة استثمارية.

## حالة البناء والتسليم

- تمت إضافة كود الموقع وواجهة API ومصدر Android واختبارات JavaScript.
- **لا يوجد APK موقّع مرفق حالياً**: بيئة هذا المستودع لا تحتوي على Java أو Gradle أو Android SDK. زر التنزيل في الصفحة معطّل بوضوح إلى حين بناء APK وتوقيعه وإرفاقه.
- تم نشر الموقع على Vercel بنجاح والتحقق من الصفحة وواجهة السعر الحية: [nabd-ayrade-ruddy.vercel.app](https://nabd-ayrade-ruddy.vercel.app/). واجهة `/api/ayrd` أعادت بيانات SGBV بنجاح عند التحقق في 27 أكتوبر 2026.
- كود المصدر مرفوع على GitHub في الفرع `arena/89ec7888-mony`، ويوجد طلب دمج مفتوح إلى `main`: [PR #1](https://github.com/Abdo12-del/Mony/pull/1).
- لا يُحفظ أي مفتاح توقيع في المستودع. ملفات keystore وملفات APK متجاهلة عبر `.gitignore`.

## البيانات والمصدَر

- واجهة API: `GET /api/ayrd`، وتتصل بعنوان ثابت فقط هو `https://www.sgbv.dz/`، فلا تقبل عنوان URL من المستخدم ولا تعمل كوسيط طلبات مفتوح.
- `npm run build` يجهز ملفات الواجهة داخل `public/` لتوافق إعداد Vercel الحالي (أمر البناء `npm run build` ومجلد الإخراج `public`).
- يحاول المحلل العثور على صف التداول الذي يحتوي AYRADE والرمز AYRD، ثم يقرأ الفتح والإغلاق المنشورين. إذا كان الإغلاق `NC` أو غير متاح، يستعمل سعر الافتتاح المتاح ويسميه صراحةً **سعر افتتاح/مرجعياً، وليس إغلاقاً**. إذا تعذرت قراءة صف موثوق أو السعر، تعيد API خطأ 502 بلا اختلاق بيانات.
- تاريخ الجلسة يعرض فقط إذا وُجد تاريخ قريب من مؤشر السوق في النص المرئي للمصدر؛ وإلا تكون القيمة `null` ويظهر «غير متاح من المصدر». الرسم في الموقع والتطبيق يعرض القراءات المحفوظة محلياً فقط؛ وليس مخططاً تاريخياً رسمياً أو بيانات غير متاحة من المصدر.
- يخدم الموقع السعر عبر `/api/ayrd` ولا يتصل المتصفح مباشرة بالمصدر. توجد مهلة للطلب، حد أقصى لحجم HTML، رؤوس أمنية وتخزين مؤقت قصير.
- موقع البورصة قد يغيّر بنية HTML أو طريقة عرض الأسعار؛ راجع الاختبارات والمحلل عند حدوث ذلك. هذا المشروع لا يقدم سعراً لحظياً.

## تشغيل الموقع محلياً

يتطلب Node.js 18 أو أحدث. خادم التطوير المرفق يستخدم Node بلا تبعيات إضافية ويشغّل API نفسها:

```bash
npm test
npm run dev
```

ثم افتح `http://localhost:4173`. لا يكفي فتح `index.html` مباشرة لأن السعر يأتي من API. وللتجربة المطابقة لبيئة Vercel يمكن تثبيت CLI وتشغيل `npx vercel dev`.

## النشر على Vercel

1. استورد هذا المستودع في Vercel، مع إعداد Root Directory على جذر المشروع.
2. لا يحتاج المشروع إلى متغيرات سرية أو قاعدة بيانات. ملف `vercel.json` يضيف رؤوساً أمنية، و`api/ayrd.js` هو مسار Node.js serverless.
3. انشر، ثم اختبر الصفحة و`/api/ayrd` من المتصفح. تحقق من الاستجابة عند نجاح المصدر وعند عدم توفره، ولا تعتبر النشر ناجحاً قبل هذا التحقق.
4. بعد رفع إصدار APK موقّع، ضعه في `downloads/nabd-ayrad.apk` أو حدّث مسار زر التنزيل وتعليمات الإصدار، وأزل حالة التعطيل. الملف الناتج مستثنى من Git افتراضياً؛ اتبع سياسة تخزين الإصدار المناسبة.

## تطبيق Android

- `android/` مشروع Android Studio / Gradle، `minSdk 26` (Android 8.0)، اتجاه RTL، وواجهة عربية.
- التطبيق يتصل مباشرة بموقع SGBV الرسمي عبر HTTPS، ويحفظ آخر قراءة ناجحة وتاريخ الفحص محلياً.
- التفعيل الأول للتنبيهات ينشئ فحص WorkManager دورياً كل 15 دقيقة مع شرط اتصال الشبكة. الفترة 15 دقيقة هي الحد الأدنى الدوري لـ WorkManager، وليست موعداً مضموناً؛ قد يؤخر Android التنفيذ. لا يوجد تنبيه عند أول قراءة: تحفظ كأساس للمقارنة. التنبيهات اللاحقة والسجل المحلي ينتجان عند اختلاف السعر بين قراءتين ناجحتين.
- إذا فشل الاتصال أو التحليل، يبقى آخر سعر ناجح كما هو ولا يضاف سجل أو تنبيه. عند التشغيل اليدوي يظهر سبب التعذر للمستخدم.
- إذن `POST_NOTIFICATIONS` يُطلب عند تفعيل التنبيهات على Android 13 فأحدث. يعتمد استمرار العمل بعد إعادة التشغيل على جدولة WorkManager واستعادة مهامه من النظام. الإيقاف الإجباري يوقف المهام حتى يفتح المستخدم التطبيق مجدداً. قد يفوت التغير بين فحصين، والتنبيهات ليست لحظية أو مضمونة.

### البناء في Android Studio

1. ثبّت Android Studio حديثاً مع Android SDK 35 وJDK 17.
2. يتطلب إعداد المشروع Gradle 8.7 مع AGP 8.6.1. لا يحتوي المستودع على Gradle Wrapper؛ إذا كان Gradle 8.7 مثبتاً، أنشئه من مجلد `android/` بالأمر `gradle wrapper --gradle-version 8.7` ثم افتح المجلد في Android Studio.
3. ابنِ نسخة debug للتحقق والتجربة: من `android/` شغّل `./gradlew :app:assembleDebug` (أو استخدم Build في Android Studio).
4. لاستخدام إصدار نهائي، أنشئ مفتاحاً خاصاً خارج المستودع واستخدم **Build > Generate Signed Bundle / APK**. احتفظ بنسخة احتياطية مشفرة للمفتاح وكلمات مروره في مدير أسرار خاص؛ لا ترفعها إلى Git أو تشاركها. Android Studio يصدر APK موقّعاً، ويمكن بعدها توفيره للتنزيل. لا توجد مفاتيح أو APK موقّع في هذا المستودع.
5. التثبيت اليدوي يتطلب Android 8.0 أو أحدث؛ على بعض الأجهزة يجب السماح بالتثبيت من المصدر الذي فُتح منه الملف. افتح التطبيق، فعّل التنبيهات، واسمح بالإشعارات عند الطلب.
